Agents work side by side. Your tests decide what's done.

  1. 01

    Plan

    A planner reads your repo and splits the task into pieces that can run side by side.

  2. 02

    Build

    Each piece gets its own agent and its own git worktree, so nobody overwrites anybody.

  3. 03

    Check

    Your tests run after every change. A failure goes straight back to the agent that caused it.

  4. 04

    Merge

    A reviewer reads every diff. Nothing reaches main until you say so.

Questions

Before you ask.

Is it free?

Yes. The desktop app is open source under the MIT license, and it runs on your machine. You bring your own model access.

Which AI does it use?

Two kinds of workers. Claude Code runs through your existing Claude Pro or Max plan, and the built-in helloagents agent runs on the Claude API with your own key (Claude Opus 5 by default).

Does my code leave my machine?

Only to the model provider you choose, the same as using Claude Code directly. Traces, logs and runs are stored locally in a SQLite file.

Can an agent break my repo?

Each agent works in its own git worktree on its own branch. Agents can't write outside it, commands run without a shell from an allowlist, and nothing reaches main until you approve the merge.

When can I download it?

The agent harness and trace store work today from the terminal. The orchestrator and the macOS app are in progress. Star the repo on GitHub to follow along.
