how a run works

Agents work in parallel. Your tests decide when they're done.

  1. 01
    PlanA planner reads your repo and splits the task into pieces that can run side by side.
  2. 02
    BranchEach piece gets its own agent on its own git worktree, so agents never overwrite each other.
  3. 03
    CheckYour tests run after every change. A failure goes back to the agent that caused it, with the output.
  4. 04
    MergeA reviewer reads every diff. Nothing reaches main until you approve it.

questions

Before you ask.

Is it free?

Yes. The desktop app is open source under the MIT license and runs on your machine. You bring your own model access: a Claude plan, an API key, or (soon) a local model.

Can I use it with only Claude Code?

Yes. The planner, the agents and the reviewer can all run through the Claude Code CLI you're signed in to, so no API key is needed.

Does my code leave my machine?

Only to the model provider you choose, the same as using Claude Code directly. Runs, traces and logs are stored locally.

Can an agent break my repo?

Each agent works on its own branch in its own worktree. Agents can't write outside it, commands run without a shell from an allowlist, and nothing reaches main until you approve the merge.

When can I download it?

The agent harness and trace store work today from the terminal. The orchestrator and the macOS app are in progress. Star the repo to follow along.
