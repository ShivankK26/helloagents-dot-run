# The UI

## Design rules

- Two themes, pure **black** and **white**, switched in the title bar (system by default).
- **Geist Sans** for text, **Geist Mono** for code and paths, everywhere.
- Orange `--accent` only for the main action and live work; green ok, red bad,
  yellow "needs you".
- Short, plain copy. No explanations the user didn't ask for.
- Nothing cut off: menus measure the window and open up or down; long commands
  are clamped; paths are shown relative to the project (`~` for home).

## Screens

- **Title bar** (44px, aligned with the window buttons): project switcher,
  breadcrumb, ⌘K search ("Search or run a command"), theme switch.
- **Feed rows for agent requests**: `run` steps ("New run in X: <task>" · Open);
  ships the agent asked for show as ship rows mid-turn without closing the turn;
  `Task` calls read "Sub-agent: <description>".
- **⌘K palette**: opens centered in the window; drag it by the grip on top (or the
  search row's edges) and it stays there until the app quits; double-click the
  grip to re-center. Always kept fully on screen, above the sidebar and title bar.
- **Sidebar** (slides open/closed, or peeks on hover when hidden): search, Overview,
  Traces, Errors, Evals (soon); runs **By status** (Needs you / Working / Done) or
  **By project** as a tree; project "⋯"/right-click native menu (Show in Finder,
  Remove…); Add a project; Claude Code version in the footer.
- **New task** (per project): "What should we build in <project>?", branch and
  checks line, the composer:
  - text box (Enter sends, Shift+Enter new line, `/` opens commands, skills and MCP connectors;
    picking a connector inserts "Using the X connector, "; the follow-up box has the same
    menu, minus /model and /effort);
    grows with the text, and a grip on its bottom edge drags it taller or shorter
    (remembered; double-click resets). The follow-up box has the same grip on top.
  - **drafts**: unsent text and images stay with the project (and the follow-up
    box with its run) when you switch away, and survive a restart (localStorage,
    `helloagents.draft.<projectId>` / `.run.<runId>`); sending clears them.
  - image button and drag/drop/paste for screenshots (thumbnails)
  - agent + model picker, effort, **mode** (Auto / Ask for commands / Plan first / Full access)
  - "1 attempt" (several attempts: later), run button
  - under it: New branch / Current checkout, setup hint, "from <base branch>"
- **Run screen**:
  - header: back, title, status pill, **where-is-code pill**, Run checks, Dev
    server, Open (in editor/Finder/Terminal), Ship menu, ⋯ (copy branch, discard)
  - stage line while working: Read the code → Make the change → Run the tests → Wrap up
  - tabs: **Activity** (one centered column), **Changes** (file tree + diff; under the
    tree: This run facts, Where the time went, Open trace), **Trace**
  - Activity opens scrolled to the newest step and follows new steps (and images
    loading) while you're at the bottom; scrolling up pauses that. Ship steps and
    approval cards always scroll into view.
  - Activity: summary card when done, "You" bubbles (attachment chips), agent
    messages (Markdown), grouped steps (Explored N files, Edited +/−, Ran, Checks,
    screenshots inline), approval / plan / background / connect-to-GitHub cards,
    "Done" line per turn with ship buttons, helloagents steps (Pushed…, Freed…)
  - follow-up box (Dock) at the bottom, never locked: while working it says "Add to
    what it's doing"; typing "push it" when idle ships instead of messaging the agent
- **Overview, Traces, Errors** pages; **Evals** is a placeholder.
- **Add a project** dialog: choose folder or clone a URL; review step with name and agents.
- **Remove project** confirm: what you lose (runs, traces, saved checks) and what stays (folder, branches).
- Toasts bottom-right; selecting text copies it ("Copied").

## Behaviours worth knowing

- Notifications when a run finishes or needs approval while the app is in the background.
- Quitting with agents working asks first, then stops them cleanly.
- Menus: `Menu.tsx` with `openSignal` to open from code (`/model`, `/effort`).
