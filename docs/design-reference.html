// what you're installing

Two kinds of files

Both are plain markdown with YAML frontmatter. Claude Code picks them up from your project's.claude/ folder, or from ~/.claude/ for every project.

sub-agent

A specialist Claude can hand work to

A sub-agent runs in its own context window with its own system prompt and tool allowlist. Claude delegates to it when a task matches its description, or when you ask for it by name. The result comes back without cluttering your main conversation.

runs in
A separate context window
triggered
Claude delegates, or you ask: "use the code-reviewer"
best for
Reviews, audits, research, test writing: focused jobs
.claude/agents/code-reviewer.md
---
name: code-reviewer
description: Reviews code changes for bugs…
tools: Read, Grep, Glob, Bash
---

You are a senior engineer doing a careful review…
skill

Know-how Claude loads when it's needed

A skill is a folder of instructions, plus optional scripts and references. Only its description sits in context until a task calls for it, then Claude reads the rest and follows it in your main conversation. You can also run it directly as /name.

runs in
Your main conversation, loaded on demand
triggered
Automatically when relevant, or with /changelog
best for
Repeatable workflows, formats and house rules
.claude/skills/changelog/SKILL.md
---
name: changelog
description: Writes a CHANGELOG.md entry from git…
allowed-tools: Bash(git log:*) Read
---

# Changelog
